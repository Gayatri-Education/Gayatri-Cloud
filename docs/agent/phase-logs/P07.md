     - Policy-driven fallback to secondary model/provider with explicit fallback notification metadata.
     - Token usage tracking (`AIExecutionUsage`).

     - `GET /api/v1/ai/connections` (list connections with masked fingerprints)
     - `DELETE /api/v1/ai/connections/{connection_id}` (delete credential)
     - `GET /api/v1/ai/models` (list discovered models and capabilities)
     - `POST /api/v1/ai/models/sync` (sync model snapshots)
     - `POST /api/v1/ai/generate` (server-side generation via gateway)
     - `POST /api/v1/ai/generate/stream` (SSE streaming generation)
