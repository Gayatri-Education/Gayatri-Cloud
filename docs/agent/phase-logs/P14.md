## 1. `/plan` — Goal and Scope

- **Master-plan section:** Section 5, Phase P14 (`GAYATRI_CLOUD_PHASE_BY_PHASE_DEVELOPMENT_PLAN.md`)
- **Requirements IDs:** `RQ-003`, `RQ-005`, `RQ-006`, `RQ-025`, `RQ-026`, `RQ-038`
- **Prerequisite phases and verified statuses:** P00 through P13 all `GREEN`.
- **Explicit in-scope work:**
  1. Backend Parent Domain & Services (`backend/app/domain/parent/service.py`):
     - `ParentService`:
       - Guardian relationship management: query linked children, submit linking requests, verify/approve links, revoke links immediately.
       - Child learning progress aggregation: overall mastery, active courses, completed assessments, study time, and misconception remediation status.
       - Institution-controlled privacy filter: strict server-side redaction ensuring raw student-AI tutoring transcripts are NEVER exposed to the parent API; only high-level conceptual summaries, competencies, and study metrics are delivered.
       - Teacher communications: child-relevant course announcements and school notices.
       - Sensitive child record access audit logging: emits structured audit events upon record retrieval.
  2. Backend REST API Endpoints (`backend/app/api/v1/parent.py`):
     - `GET /api/v1/parent/children`: List all linked children with verification status and summary cards.
     - `POST /api/v1/parent/link-request`: Submit linking request between parent and student.
     - `POST /api/v1/parent/children/{relationship_id}/verify`: Approve/verify relationship.
     - `DELETE /api/v1/parent/children/{relationship_id}`: Immediately revoke guardian link.
     - `GET /api/v1/parent/children/{student_id}/progress`: Privacy-filtered mastery and activity metrics.
     - `GET /api/v1/parent/children/{student_id}/assessments`: Assessment scores and teacher feedback.
     - `GET /api/v1/parent/children/{student_id}/communications`: Class announcements and school notices.
  3. Frontend Parent Architecture & Components:
     - Types in `frontend/src/lib/types/parent.ts`:
       - `LinkedChild`, `ChildProgressSummary`, `ChildAssessmentReport`, `ChildCommunicationItem`.
     - Client methods in `frontend/src/lib/api-client.ts`.
     - Components in `frontend/src/components/parent/`:
       - `ChildSelector.tsx`: Seamless multi-child toggle with child avatar and active state.
       - `ChildProgressOverview.tsx`: Mastery progress gauge, study time, active streak, subject cards.
       - `ChildAssessmentList.tsx`: Assessment scores, teacher remarks, competency badges.
       - `GuardianLinkManager.tsx`: Manage linked children, pending verifications, link new child.
       - `SchoolCommunications.tsx`: Announcements from child's teachers and school notices.
     - Pages (Next.js 14 App Router):
       - `/parent/dashboard`: Main parent workspace with multi-child selector and progress cards.
       - `/parent/children`: Relationship verification and linking manager.
       - `/parent/assessments`: Assessment records and teacher feedback.
       - `/parent/communications`: Class notices and school announcements.
     - Navigation:
       - Update `frontend/src/components/common/Navbar.tsx` to display Parent Portal link when active role is `PARENT`.
  4. Tests:
     - Backend tests (`backend/tests/test_parent.py`):
       - Parent cannot view unlinked student (`403 Forbidden`).
       - Revoked relationship denies access immediately (`403 Forbidden`).
       - Privacy filter: raw tutoring dialogue is never returned in summary.
       - Multiple-child switching without data leakage.
       - Relationship verification approval.
       - Access audit logging on child record view.
     - Frontend tests (`frontend/tests/parent-portal.test.ts`):
       - Multi-child selection and switching.
       - Privacy-filtered metrics rendering.
       - Relationship linking and revocation actions.
       - Assessment reports and school communications.
