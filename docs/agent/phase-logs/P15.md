- **Explicit in-scope work:**
  1. Backend Admin Domain & Service (`backend/app/domain/admin/service.py`):
     - `AdminService`:
       - Strict scope separation: Platform Super-Admin (`SUPER_ADMIN`) vs. Tenant Organization Admin (`ORG_ADMIN`).
       - Organization branding & domain proof verification (DNS/TXT challenge token).
       - Global organization lifecycle (suspension/reactivation with required audit reason code).
       - Tenant member lifecycle (list members, update role assignments with RQ-003 invariant enforcement prohibiting student+teacher role collision, member suspension).
       - AI Provider & Policy administration: configure permitted providers, allowed model IDs, default routing policy, and encrypted org-level credentials without exposing raw keys.
       - Immutable audit search across `ApplicationEvent` / outbox records with category, actor, and date filters.
       - Operational health metrics: active learners, outbox queue lag, AI token consumption, and provider error rates.
  2. Backend REST API Endpoints (`backend/app/api/v1/admin.py`):
     - `GET /api/v1/admin/dashboard`: Operational metrics and system overview.
     - `GET /api/v1/admin/organizations/{org_id}`: Tenant details and settings.
     - `PATCH /api/v1/admin/organizations/{org_id}`: Update branding and configuration.
     - `POST /api/v1/admin/organizations/{org_id}/domains`: Register domain.
     - `POST /api/v1/admin/organizations/{org_id}/domains/{domain_id}/verify`: Verify DNS proof.
     - `POST /api/v1/admin/organizations/{org_id}/suspend`: Suspend tenant (super-admin only, requires reason).
     - `POST /api/v1/admin/organizations/{org_id}/reactivate`: Reactivate tenant (super-admin only, requires reason).
     - `GET /api/v1/admin/organizations/{org_id}/members`: List tenant members with roles.
     - `PATCH /api/v1/admin/organizations/{org_id}/members/{membership_id}/role`: Change role (enforces RQ-003).
     - `POST /api/v1/admin/organizations/{org_id}/members/{membership_id}/suspend`: Suspend member.
     - `GET /api/v1/admin/organizations/{org_id}/ai-policy`: View permitted models and routing policy.
     - `PUT /api/v1/admin/organizations/{org_id}/ai-policy`: Update model routing and provider policy.
     - `GET /api/v1/admin/organizations/{org_id}/audit`: Search immutable audit logs.
  3. Frontend Admin Architecture & Components:
     - Types in `frontend/src/lib/types/admin.ts`: `AdminMetrics`, `OrganizationMember`, `DomainVerification`, `AdminAiPolicy`, `AuditLogEntry`, `OrganizationDetails`.
     - API Client methods in `frontend/src/lib/api-client.ts`.
     - Components in `frontend/src/components/admin/`:
       - `AdminNav.tsx`: Shared tab navigation across admin views.
       - `AdminMetricsCards.tsx`: Top operational statistics (active members, outbox lag, token usage, courses, health).
       - `MemberManagementTable.tsx`: Searchable members list, role changer dropdown, suspension toggle, RQ-003 validation.
       - `AiPolicyManager.tsx`: Permitted models selector, routing strategy selector, masked credentials display.
       - `AuditSearchTable.tsx`: Filterable audit log with event categories, timestamps, and sensitivity badges.
       - `DomainVerificationPanel.tsx`: Domain proof instructions, TXT token copy, and verification trigger.
     - Pages (Next.js 14 App Router):
