## 4. Debugging Log

- **DEF-05: SQLite datetime timezone offset mismatch:** SQLite returns offset-naive datetimes from `SessionDevice.expires_at`. Resolved by checking `tzinfo is None` and attaching UTC prior to comparison with `datetime.now(UTC)`.
- **DEF-06: Test execution speed:** PBKDF2 with 600,000 iterations ran in ~20s across tests. Added `get_pbkdf2_iterations()` returning 10,000 during testing and 600,000 in production, reducing test suite time from 20s to 3.48s.
