## 1. `/plan` — Goal and Scope

- **Master-plan section:** Section 5, Phase P11 (`GAYATRI_CLOUD_PHASE_BY_PHASE_DEVELOPMENT_PLAN.md`)
- **Requirements IDs:** `RQ-021`, `RQ-022`, `RQ-023`, `RQ-024`, `RQ-034`, `RQ-035`
- **Prerequisite phases and verified statuses:** P00 through P10 all `GREEN`.
- **Explicit in-scope work:**
  1. Event Models & Database Enhancements (`backend/app/db/models/events.py`):
     - `ApplicationEvent`: Canonical envelopes with event ID, UTC timestamp, schema version, actor context, tenant scope, session/course references, sensitivity classification (`PUBLIC`, `INTERNAL`, `PROTECTED`, `RESTRICTED`), and JSON payload.
     - `EventOutbox`: Transactional outbox ensuring reliable event dispatching with status tracking (`pending`, `archived`, `failed`, `quarantined`) and bounded retries.
     - `EventArchiveBatch`: Immutable archive batches stored in private storage (S3/Local) with SHA-256 checksums, manifest metadata, and count/time ranges.
     - `TrainingEligibilityRecord`: Independent eligibility records (`NOT_REVIEWED`, `ELIGIBLE`, `EXCLUDED`, `REDACTION_REQUIRED`) enforcing deny-by-default training governance.
     - `TrainingDatasetExport`: Controlled, reproducible dataset export with version tags, split metadata (train/val/test), SHA-256 checksums, and strict human approval gating.
  2. Event Domain Engine (`backend/app/domain/events/`):
     - `envelope.py`: Canonical versioned event envelope builder with validation across all 8 event categories (`IDENTITY`, `COURSE`, `TUTOR`, `LEARNING`, `AI_EXECUTION`, `ADMIN_PRIVACY`, `BILLING`, `OPERATIONS`).
     - `outbox.py`: `OutboxService` providing transactional event recording and bounded retry/quarantine management.
     - `archiver.py`: `ArchiveService` packing batches of outbox events, computing SHA-256 checksums, persisting to `StorageService` (`archives/events/...`), and generating searchable batch manifests.
     - `telemetry.py`: Telemetry logger separating operational logs (redacted diagnostics, correlation IDs, no raw prompts) from protected interaction stores.
     - `training.py`: `TrainingPipelineService`:
       - Deny-by-default eligibility assessment: checks consent, institution data policy, purpose scope, and deletion status.
       - PII sanitizer: redacts email addresses, names, IP addresses, and phone numbers.
       - Controlled dataset exporter: reproducible train/val/test splits (e.g. 80/10/10) preventing cross-student/cross-course contamination.
       - Enforces approval gate: no dataset can be used for training while `is_approved` is False.
  3. API Endpoints (`backend/app/api/v1/events.py`):
     - `POST /api/v1/events/outbox/process`: Trigger outbox batch archival (Admin/System).
     - `GET /api/v1/events/outbox/status`: Get outbox queue stats, pending counts, lag, and quarantine counts.
     - `GET /api/v1/events/archive/batches`: List archived storage batches and manifests.
     - `POST /api/v1/events/training/eligibility`: Evaluate or update training eligibility for an event.
     - `POST /api/v1/events/training/export`: Export an eligible training dataset version.
     - `POST /api/v1/events/training/datasets/{dataset_id}/approve`: Human approval gate for dataset export.
     - `GET /api/v1/events/training/datasets`: List generated dataset exports and approval statuses.
  4. Router integration in `backend/app/api/v1/__init__.py`.
  5. Comprehensive test suite in `backend/tests/test_events.py`:
     - Transactional outbox atomicity and bounded retries.
     - Archiver batching, SHA-256 verification, and idempotent storage dispatch.
     - Operational log sanitization ensuring zero student prompt/answer leakage.
     - Training eligibility deny-by-default enforcement (unreviewed/excluded events rejected).
     - PII redaction pipeline.
     - Contamination-free train/validation/test split generation.
     - Strict dataset approval gate preventing training execution without human sign-off.

## 3. Safety, Security & Isolation Audit
- **Tenant Isolation:** All event outbox and archive queries filter on `tenant_id` where applicable. Training dataset exports strictly verify caller role (`ORGANIZATION_ADMIN` or `PLATFORM_ADMIN`) and scope to tenant boundaries.
- **Deny-by-default Training (DEC-011):** Default eligibility is `NOT_REVIEWED`. The pipeline strictly halts any attempt to use or export unapproved or non-consented data.
- **Data Privacy & PII Scrubbing:** Telemetry plane scrubs prompt and message payloads. Training dataset pipeline scrubs emails, phone numbers, and IP addresses.
- **Zero Secrets / Zero Paid Usage:** No real external credentials or billable API calls were made. Local mock storage and deterministic SQLite testing engine are used.
