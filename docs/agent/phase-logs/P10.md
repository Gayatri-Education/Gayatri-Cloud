## 4. Debugging Log

- **Issue 1:** `TypeError: CanonicalMasteryService() takes no arguments`.
  - **Root Cause:** `CanonicalMasteryService.record_evidence` was designed as a `@classmethod` accepting `(session, student_id, ...)` rather than an instance.
  - **Resolution:** Replaced instance instantiation with direct classmethod call.
- **Issue 2:** Enrollment check returned 403 because enrollment status was `'enrolled'`, but service checked `status == 'active'`.
  - **Root Cause:** `CourseService.enroll_student` assigns `status='enrolled'` upon creation.
  - **Resolution:** Updated query in `AssessmentService` to check `CourseEnrollment.status.in_(["enrolled", "active"])`.
- **Issue 3:** `DeterministicGrader.grade_numerical` flagged ambiguous numbers on `'9.81 m/s^2'`.
  - **Root Cause:** Regex extracted `9.81` and `2` from unit exponent `^2` as two separate numbers.
  - **Resolution:** Added preprocessing to strip unit exponents (`r"[\^][\+\-]?\d+"` and `r"(?<=[a-zA-Z°%/\*])(?<![eE])\d+"`) before extracting student answer numbers.
- **Issue 4:** Bob (Org Admin in Org B) could view Alice's attempt in Org A because `get_attempt` only checked `context.has_role(ORG_ADMIN)`.
  - **Root Cause:** Endpoint did not verify that the attempt's offering belonged to the caller's active organization.
  - **Resolution:** Added strict tenant isolation check verifying `offering.organization_id == context.organization_id` on `get_attempt`, `autosave_attempt`, `submit_attempt`, and `teacher_override`.
