  1. Backend Security & Threat Defense (`backend/app/domain/security/`):
     - SSRF Guard (`ssrf_guard.py`): Strict validation for user-supplied custom AI endpoints, webhook URLs, and external resource URLs. Enforces protocol allowlist (`https`, `http` in dev) and blocks private IPv4/IPv6 networks, loopback (`127.0.0.1`), link-local (`169.254.0.0/16` AWS metadata service `169.254.169.254`), and multicast.

     - Account Deletion & Anonymization Lifecycle:
       - Multi-state request lifecycle: `pending` (grace period), `completed`, `cancelled`.
       - Soft-delete with immediate session invalidation and account deactivation.
       - Legal Hold & Accounting Exception: Preserves statutory financial transactions and tax invoices (`InvoiceReceipt`, `FeePayment`) per RQ-027 and P16, scrubbing PII into anonymized pseudonym identifiers (`deleted_user_<id>`).
       - Cascading purge: Deletes active sessions, refresh tokens, tutor sessions, and enrollments.

     - `POST /api/v1/security/deletion-request`: Initiate account deletion request.
     - `GET /api/v1/security/deletion-request`: Check deletion request status.
     - `POST /api/v1/security/deletion-request/cancel`: Cancel pending deletion during grace period.
     - `GET /api/v1/security/audit`: User-facing access and security log summary.

## 2. Implementation Summary

- **SSRF Guard & Path Sanitizer:**
  - `backend/app/domain/security/ssrf_guard.py`: Validates URL scheme, resolves IP literals, checks against `BLOCKED_NETWORKS` (`169.254.0.0/16`, `127.0.0.0/8`, `10.0.0.0/8`, etc.), and sanitizes file keys against `..` directory traversal and null byte injections.
- **Security Headers Middleware:**
  - `backend/app/main.py`: Injects `Content-Security-Policy`, `Permissions-Policy`, `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, and `X-Frame-Options: DENY`.
- **Data Export & Deletion Service:**
  - `backend/app/db/models/security.py`: `AccountDeletionRequest` and `SecurityAuditLog`.
  - `backend/app/domain/security/deletion.py`: `DeletionService` generating machine-readable JSON exports with SHA-256 integrity, managing 7-day deletion grace periods, invalidating sessions immediately, and applying statutory legal hold retention on financial tables with user PII pseudonymization.
  - `backend/app/api/v1/security.py`: REST routes mounted at `/api/v1/security`.
- **Frontend Privacy & Security UI:**
  - `frontend/src/lib/types/security.ts`: TypeScript interfaces.
  - `frontend/src/lib/api-client.ts`: 5 typed security methods.

## 4. Security & Isolation Verification

- SSRF attacks against AWS metadata IP `169.254.169.254` and private networks are blocked at the perimeter (`400 Bad Request`).
- Directory traversal attacks using `..` or null bytes in storage keys are rejected (`400 Bad Request`).
- Cross-user data export requests and account deletion requests are strictly prohibited (`403 Forbidden`).
- Account deletion preserves statutory billing transaction logs with PII scrubbed to pseudonymized identifiers (`deleted_<id>@anonymized.internal`).
