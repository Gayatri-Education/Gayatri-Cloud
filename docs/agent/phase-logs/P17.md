- **Requirements IDs:** `RQ-029`, `RQ-030`, `RQ-038`
- **Prerequisite phases and verified statuses:** P00 through P16 all `GREEN`.
- **Explicit in-scope work:**
  1. Backend Localization & Offline Packaging (`backend/app/domain/i18n/`):
     - `LanguageCode` Enum: `en` (English), `hi` (Hindi), `sa` (Sanskrit), `ta` (Tamil), `te` (Telugu), `kn` (Kannada), `mr` (Marathi), `bn` (Bengali).
     - Authoritative translation registry (`TranslationRegistry`):
       - Key-based dictionary lookup with parameter interpolation (`{name}`, etc.).
       - Strict fallback to English (`en`) for missing or incomplete keys.
       - User language preference persistence.
       - Separation of AI response language instructions from UI language selection.
     - Offline Course Packager (`OfflineService`):
       - Bundles approved, published course version materials into a portable, version-pinned offline package with SHA-256 integrity hash.
       - Validates package staleness against live course catalog.
  2. Backend REST API Endpoints (`backend/app/api/v1/localization.py`):
     - `GET /api/v1/localization/languages`: List the 8 supported languages with native names.
     - `GET /api/v1/localization/translations/{lang_code}`: Return translation catalog.
     - `GET /api/v1/localization/preference`: Retrieve user's language preference.
     - `POST /api/v1/localization/preference`: Update user's language preference.
     - `GET /api/v1/localization/offline-bundle/{course_id}`: Download offline course bundle.
     - `GET /api/v1/localization/offline-bundle/{course_id}/staleness`: Validate if cached bundle version is stale.
  3. Frontend i18n, Accessibility, and Offline Architecture:
     - Translation catalogs in `frontend/src/lib/i18n/catalogs.ts` for all 8 languages.
     - Context provider in `frontend/src/lib/i18n/I18nContext.tsx`:
       - `t(key, params)` translation resolution with English fallback.
       - Active locale switcher and persistence.
       - High contrast mode and font scaling controls.
     - Offline caching engine in `frontend/src/lib/offline/offline-storage.ts`:
       - Local caching of published course lessons.
       - Online/offline detection (`useNetworkStatus`).
       - Explicit guards: offline mode distinguishes cached reading from live cloud functionality; disables exams, chat turns, and payments while offline.
     - Reusable components in `frontend/src/components/localization/`:
       - `LanguageSelector.tsx`: Dropdown selector with native language scripts.
       - `AccessibilityControls.tsx`: Contrast toggle and font scaling (A / A+ / A++).
       - `OfflineIndicatorBanner.tsx`: Stale version warnings and reconnect sync alerts.
       - `OfflineCourseReader.tsx`: High-contrast, font-scalable, screen-reader accessible reader.
     - Page:
       - `/offline`: Offline library for reading cached courses when disconnected.
     - Accessibility enhancements in `Navbar.tsx` and common components (WCAG 2.1 AA contrast, semantic landmarks, aria attributes, keyboard navigation).
  4. Tests:
     - Backend tests (`backend/tests/test_localization.py`): 7 tests covering language registry, English fallback, interpolation, decoupled AI prompts, bundle packaging with SHA-256, staleness detection, and cross-tenant download isolation.
     - Frontend tests (`frontend/tests/localization.test.ts`): 6 tests covering 8 language catalogs, translations, interpolation, offline bundle storage CRUD, and API client integration.

## 4. Security & Isolation Verification

- Cross-tenant offline course access is strictly denied (`403 Forbidden`) unless the user belongs to the owning organization or has `SUPER_ADMIN` role.
- Offline mode is strictly limited to cached reading of approved, published course lessons; live cloud operations (AI chat turns, evaluations, and payments) are disabled while disconnected.
- AI language prompt instructions are generated server-side and decoupled from client UI language settings.
