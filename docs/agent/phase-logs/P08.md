- **Explicit in-scope work:**
  1. Standardized Tutoring Benchmark Suite (`backend/app/domain/benchmarks/benchmark_suite.py`):
     - Versioned suite (`v1.0.0`) evaluating core educational tutoring capabilities: Socratic scaffolding (guiding questions without premature answer revelation), conceptual explanation clarity, misconception diagnosis, step-by-step mathematical reasoning, and safety/jailbreak resistance.
  2. Automated Benchmark Evaluator (`backend/app/domain/benchmarks/evaluator.py`):
     - Multi-faceted rubric scoring: pedagogical appropriateness, factual accuracy, safety checks, and composite weighted quality score (0.0 to 100.0).
     - Eligibility threshold gating: enforces minimum composite score >= 75.0 and safety score >= 80.0 before a model is marked eligible for tutoring tasks.
     - Persists immutable evaluation records in `ModelBenchmarkRun`.
  3. Quality-First Intelligent Router (`backend/app/domain/ai/router.py`):
     - Task-aware routing: routes tasks (`tutoring`, `assessment`, `grading`, `hint`, `general`) to the highest-scoring eligible model available under active credentials.
     - Capability verification: validates context window size against task requirements.
     - Manual override support: allows verified manual selection while enforcing capability compatibility.
     - Returns transparent routing justification metadata.
  4. API Endpoints (`backend/app/api/v1/benchmarks.py`):
     - `POST /api/v1/benchmarks/run`: Execute benchmark suite against model (requires ORG_ADMIN or SUPER_ADMIN).
     - `GET /api/v1/benchmarks/runs`: List historical benchmark runs with scores and eligibility status.
     - `POST /api/v1/benchmarks/route`: Resolve quality-first routing decision for a given task.
  5. Mounted in `backend/app/api/v1/__init__.py`.
  6. Comprehensive test suite in `backend/tests/test_benchmarks.py`:
     - Test benchmark suite test cases and rubrics.
     - Test benchmark evaluator scoring and eligibility threshold gating.
     - Test quality-first routing selects highest-ranked model.
     - Test manual override acceptance and context window rejection.
