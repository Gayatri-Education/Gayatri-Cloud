## 2. Implementation Record

- Created `backend/app/core/rbac.py`:
  - `TenantContext` dataclass containing `user`, `organization_id`, `roles`.
  - `resolve_tenant_context` dependency extracting `X-Organization-ID` header and validating against active `Membership` and `RoleAssignment`. Includes super admin bypass.
  - `require_roles(*allowed_roles)` dependency factory checking user context roles.
- Created `backend/app/domain/organization.py`:
  - Enforced `ROLE_INCOMPATIBILITY_RULES` disallowing `STUDENT` and `TEACHER` within the same organization.
  - Organization creation creates `Organization` and assigns caller `Membership` with role `ORG_ADMIN`.
  - Invitation generation produces cryptographic tokens with expiry (default 7 days) and single-use status tracking.
  - Acceptance flow checks token validity, user existence, membership creation, and role assignment.
  - Guardian linking verifies student membership and links guardian with relationship confirmation.
- Created `backend/app/api/v1/organizations.py`:
  - Endpoints: `POST /`, `GET /me`, `POST /{organization_id}/invitations`, `POST /invitations/accept`, `GET /{organization_id}/members`, `POST /{organization_id}/guardians`.
- Mounted router in `backend/app/api/v1/__init__.py` under prefix `/organizations`.
- Authored integration test suite in `backend/tests/test_organizations.py`.

## 4. Debugging Log

- **Issue:** FastAPI raised `AssertionError: Path parameters cannot have default values` when `resolve_tenant_context` had a parameter named `organization_id: Annotated[str | None, Header(alias="X-Organization-ID")] = None` while endpoints had path parameter `{organization_id}`.
- **Resolution:** Renamed dependency parameter in `resolve_tenant_context` to `x_organization_id` to eliminate the name collision with the path parameter.
