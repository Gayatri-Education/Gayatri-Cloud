- **Explicit in-scope work:**
  1. Object Storage Abstraction Layer (`backend/app/core/storage.py`):
     - `StorageService` abstract interface for upload, download, presigned URL generation, file existence, and deletion.
     - `LocalStorageAdapter` for local development and deterministic offline testing.
     - `S3StorageAdapter` for AWS S3 production storage design.
     - Path traversal prevention, safe key isolation, and directory containment.
  2. File Quarantine, MIME Sniffing, and Validation:
     - Deep inspection of magic bytes / headers to detect MIME spoofing (e.g. PDF header `%PDF-`, JPEG `\xff\xd8\xff`, PNG `\x89PNG\r\n\x1a\n`, ZIP/DOCX/PPTX `PK\x03\x04`).
     - File size enforcement (max 50 MB upload limit).
     - SHA-256 cryptographic checksum calculation on upload.
  3. Course and Version Lifecycle Domain Service (`backend/app/domain/course.py`):
     - Generic course creation (`Course`) with tenant ownership or global scope.
     - Immutable `CourseVersion` management with explicit lifecycle states: `draft` -> `in_review` -> `published` -> `archived`.
     - Invariant: A `published` course version is strictly immutable. Source addition or deletion on published versions is forbidden.
     - `CourseOffering` and `ClassGroup` cohort deployment (offerings can only deploy published versions).
     - Student `CourseEnrollment` and `TeachingAssignment` management.
     - `ContentSource` tracking with storage URIs, checksums, MIME types, file sizes, and processing statuses.
  4. API Endpoints (`backend/app/api/v1/courses.py`):
     - `POST /api/v1/courses`
     - `GET /api/v1/courses`
     - `GET /api/v1/courses/{course_id}`
     - `POST /api/v1/courses/{course_id}/versions`
     - `GET /api/v1/courses/{course_id}/versions`
     - `POST /api/v1/courses/{course_id}/versions/{version_id}/publish`
     - `POST /api/v1/courses/{course_id}/versions/{version_id}/sources` (Multipart upload)
     - `GET /api/v1/courses/{course_id}/versions/{version_id}/sources`
     - `GET /api/v1/courses/{course_id}/versions/{version_id}/sources/{source_id}/download` (Authorized download URL)
     - `POST /api/v1/courses/offerings`
     - `POST /api/v1/courses/offerings/{offering_id}/enroll`
  5. Integration into API router in `backend/app/api/v1/__init__.py`.
  6. Comprehensive test suite in `backend/tests/test_courses.py` covering storage operations, path traversal attacks, MIME spoofing rejection, oversized file rejection, immutable version enforcement, offering deployment validation, and cross-tenant download isolation (IDOR protection).

## 2. Implementation Record

- Created `backend/app/core/storage.py`:
  - `StorageService` ABC defining standard methods (`upload_file`, `download_file`, `file_exists`, `delete_file`, `generate_presigned_download_url`).
  - `LocalStorageAdapter` with strict directory containment and path traversal rejection (`_resolve_safe_path`).
  - `S3StorageAdapter` targeting AWS S3 with server-side AES256 encryption and presigned URL capabilities.
  - `validate_file_content` enforcing max file size (50MB), MIME allowlist, extension matching, and magic byte validation for PDFs, images, Office documents, and null-byte rejection in UTF-8 text.
  - `sanitize_filename` stripping directories and illegal characters.
- Created `backend/app/domain/course.py`:
  - `CourseService` implementing course creation (tenant vs global), version management with automatic initial `v1.0.0` draft.
  - Immutability enforcement: once published, course versions reject adding or removing content sources.
  - Offering deployment restriction: offerings can only be created from `published` course versions.
  - Student enrollment validation checking active organization membership and `STUDENT` role.
  - Authorized download URL generator with cross-tenant IDOR checks.
- Created `backend/app/api/v1/courses.py`:
  - Endpoints for course CRUD, version creation, version publishing, multipart file uploads, source listing, presigned download URLs, offering deployment, and student enrollment.
- Mounted `/courses` in `backend/app/api/v1/__init__.py`.
- Authored integration test suite in `backend/tests/test_courses.py`.
