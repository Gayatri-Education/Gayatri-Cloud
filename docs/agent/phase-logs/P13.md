## 1. `/plan` — Goal and Scope

- **Master-plan section:** Section 5, Phase P13 (`GAYATRI_CLOUD_PHASE_BY_PHASE_DEVELOPMENT_PLAN.md`)
- **Requirements IDs:** `RQ-003`, `RQ-005`, `RQ-006`, `RQ-010`, `RQ-011`, `RQ-013`, `RQ-026`, `RQ-038`
- **Prerequisite phases and verified statuses:** P00 through P12 all `GREEN`.
- **Explicit in-scope work:**
  1. Backend Teacher Domain & Models (`backend/app/db/models/teacher.py` & `backend/app/domain/teacher/`):
     - `TeacherIntervention`: Model flagging struggling learners for teacher intervention with severity, status, acknowledgement tracking, and resolution notes.
     - `ClassAnnouncement`: Model for class/course notices posted by teachers.
     - `TeacherService`:
       - Class roster retrieval with student mastery progress and active misconception counts.
       - Student enrollment and unenrollment with tenant validation.
       - 5-tier instruction cascade management (`ORG`, `COURSE`, `CLASS`, `STUDENT`, `SESSION`) with priority sorting and expiration.
       - Class analytics aggregating mastery distributions across 5 tiers (Novice, Developing, Competent, Proficient, Master), hardest concepts, and misconception clusters.
       - Intervention queue management with teacher acknowledgement.
       - Teacher Copilot diagnostic briefing grounded in empirical learning evidence, citing uncertainty and requiring confirmation.
       - Class announcements publishing and listing.
  2. Backend REST API Endpoints (`backend/app/api/v1/teacher.py`):
     - `GET /api/v1/teacher/offerings/{offering_id}/roster`
     - `POST /api/v1/teacher/offerings/{offering_id}/enroll`
     - `DELETE /api/v1/teacher/offerings/{offering_id}/enroll/{student_id}`
     - `GET /api/v1/teacher/offerings/{offering_id}/analytics`
     - `GET /api/v1/teacher/offerings/{offering_id}/interventions`
     - `POST /api/v1/teacher/interventions/{intervention_id}/acknowledge`
     - `GET /api/v1/teacher/offerings/{offering_id}/copilot-briefing`
     - `GET /api/v1/teacher/instructions`
     - `POST /api/v1/teacher/instructions`
     - `DELETE /api/v1/teacher/instructions/{instruction_id}`
     - `POST /api/v1/teacher/announcements`
     - `GET /api/v1/teacher/offerings/{offering_id}/announcements`
  3. Frontend Teacher Architecture & Components:
     - Types in `frontend/src/lib/types/teacher.ts`.
     - Client methods in `frontend/src/lib/api-client.ts`.
     - Components:
       - `RosterTable.tsx`: Searchable student roster, enrollment/unenrollment actions, mastery progress bars, active misconception badges.
       - `InstructionEditor.tsx`: 5-tier cascade directive creator, priority slider (1-5), active directives listing, and deactivation.
       - `AnalyticsCharts.tsx`: Cohort mastery distribution breakdown, hardest concepts ranked by average score, and misconception clusters.
       - `InterventionQueue.tsx`: Severity-coded queue (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`), reason descriptions, and acknowledge/resolve workflow with notes.
       - `TeacherCopilotCard.tsx`: AI Copilot diagnostic briefing card, empirical grounding citations, confidence score, explicit uncertainty notice, and actionable recommendations.
     - Pages (Next.js 14 App Router):
       - `/teacher/dashboard`: Overview workspace with offering picker, copilot briefing card, and intervention queue preview.
       - `/teacher/roster`: Full roster view and enrollment management.
       - `/teacher/instructions`: 5-tier directive cascade manager.
       - `/teacher/analytics`: Cohort learning analytics and misconception clusters.
       - `/teacher/assessments`: Assessment oversight, audit log, and manual score overrides.
       - `Navbar.tsx`: Integrated role-aware shortcut to Teacher Portal for teachers and admins.
  4. Tests:
     - Backend tests (`backend/tests/test_teacher.py`): 7 comprehensive tests verifying roster lifecycle, cross-tenant isolation, analytics calculation, intervention acknowledgement, copilot briefing grounding, instruction cascade, and announcements.
     - Frontend tests (`frontend/tests/teacher-portal.test.ts`): 9 comprehensive tests covering client methods, tenant headers, 403 boundary rejection, instruction tiers, analytics processing, intervention workflow, and copilot grounding.
