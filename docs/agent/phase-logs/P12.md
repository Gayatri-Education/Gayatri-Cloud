## 3. Safety, Security & Isolation Audit
- **Tenant Context Isolation:** `AuthContext` clearly separates personal learning space (`organizationId: null`) from school/institutional memberships. `ApiClient` injects `X-Organization-Id` only when an organization is active, preventing cross-tenant contamination.
- **Zero Client-Side Secret Leakage:** `KeyManager` accepts API keys on submission to the server-side vault (AES-256-GCM encrypted); it renders keys strictly masked (`sk-...4f9b`) and never exposes raw secrets in client payloads or state.
- **Assessment Anti-Leakage:** Assessment views strictly query `/student-view` which runs `AssessmentSanitizer` to strip answer keys, rubrics, and solutions before reaching the browser.
- **DEC-011 Training Governance:** The AI Keys settings page provides transparent toggles explaining that interactions are deny-by-default excluded from model training without affirmative user consent.
