# Gayatri Cloud — Web Frontend

Responsive, accessible web portal for Gayatri Cloud built with Next.js, React, TypeScript, and Tailwind CSS.

## Architecture

- **`src/app/`**: Next.js App Router providing student, teacher, parent, and administrator portals.
- **`src/components/`**: Reusable UI components.
- **`src/lib/`**: Type-safe API client, SSE streaming handlers, and utilities.
- **`tests/`**: Unit and integration tests using Vitest and Testing Library.

## Local Commands

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```
